# Django Admin Customization: Dynamic Design and Enhanced Functionality

## Description
Ce projet personnalise et améliore l'interface d'administration par défaut de Django.  
Objectifs principaux :  

- Créer une expérience d'administration moderne et conviviale.  
- Ajouter des **widgets personnalisés**, un **design dynamique**, des **filtres avancés**, des **actions en masse** et des **mises à jour en temps réel**.  
- Rendre l'interface responsive et intuitive pour les utilisateurs.  

---

## Fonctionnalités

### Tableau de bord personnalisé
- Affichage des statistiques : nombre de clients, produits et commandes.  
- Graphiques interactifs pour visualiser les commandes par statut.
